# Project Dependencies

This project is a React application built with Vite. Below are the key dependencies required to run the application.

## Core Framework
- **react** & **react-dom**: The core JavaScript library for building user interfaces.
- **vite**: Next-generation frontend tooling.

## Styling & Animations
- **tailwindcss** & **@tailwindcss/vite**: A utility-first CSS framework (v4).
- **framer-motion**: A production-ready motion library for React.
- **lucide-react**: Beautiful & consistent icons.

## 3D Graphics
- **three**: The standard 3D library for the web.
- **@react-three/fiber**: A React renderer for Three.js.
- **@react-three/drei**: Useful helpers for React Three Fiber.

## Installation

To install all dependencies, run the following command in your terminal:

```bash
npm install
```

Or use the provided helper script:

```bash
./install_dependencies.sh
```
